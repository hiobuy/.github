# HioBuy Developer Platform

Build applications with **Taobao, 1688, AI product discovery, China sourcing, procurement, warehouse fulfillment, and international shipping APIs**.

HioBuy provides developer infrastructure for teams building cross-border commerce and AI-powered sourcing applications connected to China's e-commerce ecosystem.

## 🚀 Get Started

Explore HioBuy with our open-source developer examples.

### [HioBuy Starter](https://github.com/hiobuy/starter)

A minimal Next.js storefront demonstrating how to integrate the HioBuy Product API.

* Keyword product search
* Image search
* Taobao / 1688 product link parsing
* Product details
* SKU and variant selection
* Server-side API key handling

**[View Source](https://github.com/hiobuy/starter)** · **[Live Demo](https://starter.demo.hiobuy.com)**

### [AI Product Finder](https://github.com/hiobuy/ai-product-finder)

A conversational AI sourcing demo powered by the HioBuy Agent API.

Search for products from China using natural language or product images and display the results directly inside an AI conversation.

* Natural-language product discovery
* Image-based product search
* Conversational sourcing experience
* 1688 / Taobao product discovery
* Agent tool calls
* Product result carousel
* Server-side API key handling
* Cloudflare deployment

**[View Source](https://github.com/hiobuy/ai-product-finder)** · **[Live Demo](https://ai-product-finder.demo.hiobuy.com)**

## 🛠 What You Can Build

HioBuy APIs provide infrastructure for building:

### Product Discovery

Search and retrieve products, SKUs, pricing, images, and product information from supported Chinese marketplaces.

### AI Sourcing Applications

Build AI product finders, sourcing assistants, shopping agents, Telegram or Discord bots, and other AI-powered commerce experiences using HioBuy Agent APIs and MCP.

### Procurement

Create sourcing and purchasing workflows for products from China.

### Warehouse Fulfillment

Receive packages at HioBuy warehouses, manage packages, request value-added services and consolidation, and prepare international shipments.

### International Shipping

Retrieve shipping options, estimate freight, create shipments, and track international deliveries.

### AI Agents & MCP

Give AI agents access to HioBuy commerce capabilities through Agent APIs and MCP-compatible tools.

Combine product discovery, sourcing, procurement, fulfillment, and logistics capabilities with your own AI applications.
