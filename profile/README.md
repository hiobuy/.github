# HioBuy Developer Platform

Build applications with **Taobao, 1688, China sourcing, procurement, warehouse fulfillment, and international shipping APIs**.

HioBuy provides developer infrastructure for teams building cross-border commerce applications connected to China's e-commerce ecosystem.

## 🚀 Get Started

The fastest way to explore HioBuy is with our open-source Next.js starter.

### [HioBuy Starter](https://github.com/hiobuy/starter)

A minimal storefront demonstrating how to integrate the HioBuy Product API.

* Keyword product search
* Image search
* Taobao / 1688 product link parsing
* Product details
* SKU and variant selection
* Server-side API key handling

**[View Source](https://github.com/hiobuy/starter)** · **[Live Demo](https://starter.demo.hiobuy.com)**

## 🛠 What You Can Build

HioBuy APIs provide infrastructure for building:

**Product Discovery**

Search and retrieve products, SKUs, pricing, images, and product information from supported Chinese marketplaces.

**Procurement**

Create sourcing and purchasing workflows for products from China.

**Warehouse Fulfillment**

Receive packages at HioBuy warehouses, manage packages, request consolidation, and prepare international shipments.

**International Shipping**

Retrieve shipping options, estimate freight, create shipments, and track international deliveries.

**AI & MCP**

Connect HioBuy commerce capabilities with AI agents and MCP-compatible applications.
